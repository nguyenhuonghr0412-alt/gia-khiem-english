⚙️ Cài Đặt Gemini AI (Lưu An Toàn Trên Máy)

Mã API Key được lưu hoàn toàn cục bộ trong localStorage trên trình duyệt của gia đình để tự động tạo bài học mới mỗi ngày.

💡 Hướng dẫn lấy Gemini API Key miễn phí (chỉ mất 30 giây):
  1. Truy cập trang chính thức của Google: https://aistudio.google.com/app/apikey
  2. Đăng nhập bằng tài khoản Gmail của bố hoặc mẹ.
  3. Bấm nút màu xanh "Create API key" (Tạo khóa API).
  4. Bấm "Copy" mã khóa (bắt đầu bằng chữ AIzaSy...) và dán vào ô phía trên rồi bấm Lưu API Key!
